## Selected Work

## 🚀 Selected Projects

### 🧠 Text-to-SQL with Language Models

Translating natural-language questions into SQL using database schemas
and language-model fine-tuning.

- Worked with the **Spider benchmark** to explore SQL generation across multiple schemas.
- Used **Unsloth, PEFT, and LoRA** for parameter-efficient fine-tuning.
- Compared generated queries against reference queries using execution accuracy and other evaluation measures.
- Improved execution accuracy from **42% to 70%** in the project experiments.

**Tools:** Python · SQL · LLaMA · SQLCoder · Unsloth · PEFT · LoRA

[Explore the repository →](https://github.com/bzay1729/spider-text-to-sql-finetuning)

### 📚 Telecom Document Search with RAG

A retrieval-augmented generation project for finding relevant information
in telecom documents and using it as context for generated answers.

- Extracted document text using **PyMuPDF**.
- Created embeddings with **MiniLM-L6-v2**.
- Used **FAISS** to retrieve relevant document content.
- Connected retrieved context with language models to support question answering.

**Tools:** Python · PyMuPDF · MiniLM · FAISS · Language Models

*Developed during the AT&T and SMU Data Science Scholars Program.*

### 📰 Media Bias Detection

An NLP project exploring the classification of political and media bias
in news text using transformer-based methods.

**Focus:** Text Classification · NLP · Transformers

[Explore the repository →](https://github.com/bzay1729/media-bias-detection-nlp)

### 🛡️ Phishing Detection

A project exploring machine learning and NLP approaches to identifying
phishing content, including classical and deep-learning models.

**Focus:** Cybersecurity · NLP · Machine Learning

[Explore the repository →](https://github.com/bzay1729/PhishingDetection)

### 📊 Telecom Customer Churn — In Progress

An end-to-end project focused on understanding customer churn
and building a reproducible prediction workflow.

**Current work:** Data validation and exploratory analysis.
